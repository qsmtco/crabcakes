# Web Fetch Tool

Fetch content from URLs and process it using AI capabilities.

## How to Use

Provide a URL to fetch content from. The tool will:
- Download the page content
- Extract readable text
- Process with AI if needed

## Best Practices

**Use for reference.** Fetch documentation, articles, or other web content to inform your work.

**Verify URLs.** Only fetch URLs you're confident are legitimate. Check with the user if unsure.

**Don't over-fetch.** Get the specific content you need rather than fetching large amounts of irrelevant material.

## Common Uses

- Fetching API documentation
- Reading technical articles
- Getting reference material
- Retrieving specifications
