# Ask User Question Tool

Present questions and options to the user for decision-making.

## When to Use

- When you need user input to proceed
- When presenting choices that need user judgment
- When showing concrete artifacts for comparison

## Presenting Options

When showing options for comparison, include previews for:
- ASCII mockups of UI layouts or components
- Code snippets showing different implementations
- Diagram variations
- Configuration examples

Preview content renders as markdown in a monospace box. Multi-line text is supported. When any option has a preview, the UI switches to a side-by-side layout.

**Skip previews for simple preference questions** where labels and descriptions suffice.

## Best Practices

**Be specific.** Ask clear, focused questions.

**Provide context.** Give the user enough information to make an informed decision.

**Don't overload.** Present options clearly without overwhelming the user.
