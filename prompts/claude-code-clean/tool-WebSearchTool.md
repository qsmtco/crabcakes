# Web Search Tool

Search the web for current information, recent events, documentation, or anything that requires up-to-date data.

## How to Use

Provide a search query. The tool returns relevant results with titles, URLs, and summaries.

## Best Practices

**Use for current information.** When you need the latest data, documentation, or news.

**Be specific.** Detailed queries return better results than vague ones.

**Verify sources.** Check that search results are from authoritative sources when accuracy matters.

## Common Uses

- Finding documentation for libraries/frameworks
- Looking up API specifications
- Researching solutions to problems
- Getting current information for a task
