# File Write Tool

Create new files or overwrite existing files with content you provide.

## Before Creating

**For existing files:** You MUST read the file's current contents first. This tool will fail if you didn't read the file first.

**For new files:** Check that a similar file doesn't already exist. Prefer editing existing files over creating duplicates.

## When to Use

- Creating new source files
- Creating new configuration files
- Creating documentation
- Saving generated content

## When NOT to Use

- Modifying existing files — use the edit tool instead
- Creating files that could be added to existing files
- Creating temporary files — use a scratchpad directory

## Best Practices

**Be certain the file is needed.** Don't create files unless necessary for the goal.

**Match existing style.** Follow project conventions for file naming, structure, and formatting.

**Include necessary headers.** For source files, include appropriate imports, declarations, and structure.

**Verify after creating.** Check that the file was created correctly.
