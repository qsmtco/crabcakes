# Task Update Tool

Update an existing task's status, content, or other fields.

## When to Use

- Mark a task as completed
- Change task status (pending → in_progress → completed)
- Update task description
- Assign or reassign a task

## Task States

- **pending**: Task not yet started
- **in_progress**: Currently working on
- **completed**: Finished successfully

## Best Practices

- Update status in real-time as you work
- Mark completed IMMEDIATELY after finishing (don't batch)
- Keep exactly ONE task in_progress at a time
- If blocked, create a new task describing what needs resolution
- Never mark complete if tests fail or implementation is partial
