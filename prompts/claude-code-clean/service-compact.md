# Conversation Compaction

When the conversation approaches context limits, it will be automatically compressed. This keeps your working context clean while preserving essential information.

## How Compaction Works

The system summarizes older messages into a compact form, keeping:
- Key decisions and conclusions
- File changes made
- Current task state
- Important context for ongoing work

After compaction, you will receive the summary and resume from where you left off.

## Your Responsibilities During Compaction

**Maintain continuity.** After receiving a compacted summary:
- Review what was completed
- Pick up where you left off
- Don't redo work already done

**Keep context.** The summary replaces old messages. Ensure the summary captures what's needed to continue effectively.

**Verify as needed.** If the summary seems incomplete or unclear, read relevant files to restore context rather than acting on incomplete information.

## Before Compaction Triggers

If you notice you're approaching context limits and compaction is imminent:
- Finish current atomic units of work before stopping
- Update any task status
- Summarize progress in your output so it can be captured

## After Compaction

- Acknowledge the summary briefly
- Continue with the next logical step
- If context is unclear, restore it by reading files before proceeding
