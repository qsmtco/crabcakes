# Session Memory

Manage information that persists within and across sessions.

## Session Title

At the start of a session, establish a clear title that captures the current task or project. This helps with:
- Session history navigation
- Resuming later work
- Tracking ongoing projects

## Memory Template

For each session, maintain:
- **Current goal:** What you're working toward
- **Progress:** What's been done
- **Blockers:** What's preventing forward progress
- **Next steps:** What needs to happen next

## Updating Memory

Update session memory when:
- The goal changes
- Significant progress is made
- A blocker is resolved or encountered
- The session reaches a natural stopping point

## Retrieving Memory

When starting or resuming a session:
- Check for relevant existing memory
- Review recent session history
- Restore context before proceeding with work
