# Enter Plan Mode Tool

Switch to planning mode for complex tasks. In plan mode, you analyze the task and create a detailed plan before implementation.

## When to Use

- Complex multi-step tasks
- Tasks requiring careful architecture decisions
- When the user wants to review the approach before implementation
- Tasks with significant uncertainty

## How It Works

1. You analyze the task and create a plan
2. The plan is written to a plan file
3. User reviews and approves before you proceed
4. Once approved, you exit plan mode and implement
