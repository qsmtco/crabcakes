# Send Message Tool

Send messages to teammates or broadcast to the team.

## When to Use

- Communicate with other agents
- Share findings with teammates
- Request help or information
- Broadcast updates to the team

## Best Practices

- Your text output is NOT visible to other agents — use this tool to communicate
- Messages are delivered automatically; don't check an inbox
- Refer to teammates by name, not UUID
- Don't quote original messages when relaying — it's already rendered
